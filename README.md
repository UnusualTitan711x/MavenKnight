# ⚔️ Maven Knight

Maven Knight is a 3D dungeon-crawling action-adventure game built with Godot, inspired by *The Legend of Zelda* and *Dark Souls*.

Fight skeletons, navigate the dungeon, and reach the end of each level.

## 🎮 Play the Game

**[Play Maven Knight on itch.io](https://unusualtitan711.itch.io/maven-knight)**

Play in your browser or download a desktop build for Windows, macOS, or Linux. For the best experience, the desktop version is recommended.

## About the Game

Maven Knight combines dungeon exploration with real-time combat. Defeat every skeleton in the level, then reach the pink podium to complete it.

### Features

- 3D dungeon environments
- Real-time combat against skeleton enemies
- Player movement and dashing
- Level completion through enemy elimination
- Browser and desktop builds

### Controls

| Action | Key |
|---|---|
| Move | WASD |
| Attack | Left Mouse Button / J |
| Dash | Space |
| Restart | R |

## Getting Started

### Play the Published Game

Visit the [itch.io page](https://unusualtitan711.itch.io/maven-knight) to play in your browser or download a build for your operating system.

### Run from Source

1. Install [Godot Engine 4.4](https://godotengine.org/).
2. Clone this repository:

   ```bash
   git clone https://github.com/UnusualTitan711x/MavenKnight.git
   ```

3. Open Godot, choose **Import**, and select `project.godot` in the cloned folder.
4. Allow Godot to import the project resources, then press **F5** to run the game.

## Built With

- **Engine:** Godot 4.4
- **Programming Language:** GDScript
- **Physics:** Jolt Physics 3D
